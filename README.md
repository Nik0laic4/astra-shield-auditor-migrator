
# Astra Shield-Auditor & Migrator [Astra Linux SE 1.8]

## Назначение
Утилита предназначена для автоматизации аудита безопасности и бесшовного переноса пользовательских данных при миграции информационных систем на операционную систему **Astra Linux Special Edition 1.8** (режим защиты «Смоленск»).

Главная задача инструмента — автоматическое выявление и корректное разрешение конфликтов между дискреционной (DAC) и мандатной (MAC/PARSEC) моделями управления доступом на этапе импортозамещения софта.

## Ключевой функционал
* **Слепой аудит:** Автоматическая проверка текущего состояния запущенных сетевых служб (SSHD, локальные прокси) и дефолтных правил файрвола (`iptables`).
* **Конвертация прав доступов:** Корректный перенос файлов с автоматическим выставлением уровней конфиденциальности (мандатных меток от Public до Secret) и сохранением целостности данных.
* **Инвентаризация:** Генерация структурированных логов и отчетов по результатам сканирования прав учетных записей (включая работу с административными аккаунтами).

## Быстрый запуск (Quick Start)

> **Внимание:** Для корректного аудита системы и чтения параметров PARSEC требуются права суперпользователя (`root`).

1. Клонируйте репозиторий на целевую машину под управлением Astra Linux:
```bash
git clone https://github.com
cd astra-shield-auditor-migrator
```

2. Запустите скрипт экспресс-аудита системы:
```bash
sudo chmod +x src/auditor.sh
sudo ./src/auditor.sh --check-all
```

## Системные требования
* **ОС:** Astra Linux Special Edition 1.8 (Смоленск)
* **Окружение:** Оболочка Bash / Zsh
* **Права:** Доступ к учетной записи `admin` или `root`
